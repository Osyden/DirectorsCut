# Cliff geology pass 4

Owner: Codex cliff worker, `codex/crater-geology-pass4`, based on `24c0fcb`. Geometry-only candidate for root's next actual render. Inspected `supported_shore_core.png` and `wide_0300.png`: the rejected wall has enormous projecting horizontal cap shelves, broad black undersides and a layered-dam silhouette. It is not credible geology.

The largest fracture system changed from 23 wide cells with 210m amplitude input to 89 tall cells with 21m input; middle and small fractures are shallower and vertically elongated too. Uneven vertical erosion clefts recess into the wall. Geometric recess tint follows these actual clefts rather than broadly darkening between the old large blocks. The continuous radial foundation now has a steeper main escarpment between a battered foot and shoulder; its inflection height varies around the circumference. Removing the old shelves alone exposed the previous nearly conical slope, so this foundation correction is necessary to retain cliff-like main faces.

Only `DCCliffGenerator.h` production geometry changed. Exact shoreline correction, toe, radial endpoints, crater dimensions, route, terrain sampling, top plateau and temple supports are unchanged. No water shader, sky, lighting, whitewater mesh or VDB code was edited. Cliff face paths changed, so regenerate fitted waterfall profiles/caches after integration; existing volume data cannot be assumed aligned.

Validation: `python Tools/probe_cliff_geometry.py` runs the actual existing cliff automation bodies through the shared CPU math shim; all pass. New checks limit local relief to below25m and require the fracture relief to persist vertically at equal physical sampling distances, catching the old broad horizontal caps. `python Tools/probe_waterfall_contacts.py` checks all nine actual mean-water contacts. Neither tool starts/builds Unreal or uses GPU. Generated sources/results are ignored under `Saved/GeometryProbe`. Root still owns engine automation and the actual visual comparison.

Self-critique: this is a substantive correction to mass and fracture proportions, not a finished AAA cliff claim. The mesh still samples roughly metre-to-multi-metre features; small geology relies on the existing stone material, which may still look muddy or planar in the close view. The broad foundation can still read as a basin wall without enough directional illumination and detail. Judge supported-shore close view and the same wide camera before accepting; verify that long erosion cuts look irregular rather than evenly spaced fluting and that near-water support remains intact. Future freefall cascade behaviour remains outside this pass.
